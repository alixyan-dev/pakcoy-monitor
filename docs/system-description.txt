Sistem Website Monitoring Pakcoy

Gambaran Umum Sistem
Website Monitoring Pakcoy adalah sebuah sistem berbasis web yang dirancang untuk memantau dan memprediksi pertumbuhan tanaman pakcoy secara cerdas. Sistem ini bekerja dengan menggabungkan dua sumber data utama, yaitu data sensor yang tercatat dalam file Excel berisi 380 hari pengamatan dengan tiga kali pengukuran per hari pada pukul 08.00, 12.00, dan 16.00, serta data citra berupa foto-foto tanaman pakcoy yang diambil pada setiap periode pengamatan. Kedua sumber data ini kemudian diproses oleh sebuah model deep learning bernama Multimodal CNN-LSTM yang mampu menganalisis gambar tanaman sekaligus membaca pola perubahan data sensor dari waktu ke waktu. Hasil analisis model ini kemudian ditampilkan dalam bentuk dashboard interaktif yang dapat diakses oleh pengguna melalui browser, lengkap dengan prediksi kondisi tanaman empat hari ke depan dan rekomendasi perawatan yang dihasilkan oleh kecerdasan buatan.
Secara keseluruhan, alur kerja sistem ini dapat dibayangkan sebagai sebuah rantai proses yang dimulai dari pengumpulan data mentah, dilanjutkan dengan pengolahan dan pelatihan model, kemudian diakhiri dengan penyajian hasil prediksi kepada pengguna melalui antarmuka web yang ramah dan mudah dipahami. Ketika seorang pengguna membuka website, sistem secara otomatis mengambil data terbaru dari database, menjalankan model prediksi, dan menampilkan hasilnya dalam hitungan detik tanpa memerlukan interaksi manual yang rumit.
Cara Kerja Halaman Dashboard
Halaman Dashboard merupakan halaman utama yang pertama kali dilihat pengguna ketika mengakses website. Halaman ini berfungsi sebagai pusat pemantauan kondisi tanaman pakcoy secara real-time. Ketika pengguna membuka halaman ini, frontend yang dibangun dengan Next.js akan mengirimkan permintaan ke backend FastAPI untuk mengambil data sensor terkini dari database. Backend kemudian melakukan query ke database SQLite atau PostgreSQL untuk mendapatkan baris data terakhir yang tercatat, yang berisi informasi tentang kelembaban tanah, suhu lingkungan, kondisi tanah, tingkat kematangan, dan stage pertumbuhan tanaman saat ini.
Data yang diterima dari backend kemudian ditampilkan dalam bentuk tiga kartu sensor yang masing-masing menunjukkan nilai kelembaban tanah dalam persen, suhu dalam derajat Celsius, dan status kondisi tanah yang dikategorikan sebagai Wet, Optimal, atau Dry. Setiap kartu dilengkapi dengan indikator warna yang memudahkan pengguna memahami kondisi secara sekilas, di mana warna hijau menandakan kondisi optimal, biru menandakan kondisi basah, dan merah menandakan kondisi kering yang memerlukan perhatian. Selain kartu sensor, halaman ini juga menampilkan progress bar yang menunjukkan tingkat kematangan tanaman dalam persentase, sebuah badge yang menampilkan stage pertumbuhan saat ini seperti Initial Stage, Vegetative Stage, Pre-Harvest Stage, atau Harvest Ready, serta grafik garis yang menggambarkan tren kelembaban dan suhu selama 30 hari terakhir sehingga pengguna dapat melihat pola perubahan kondisi tanaman dari waktu ke waktu. Di bagian bawah halaman, terdapat preview singkat prediksi empat hari ke depan yang mengajak pengguna untuk melihat detail lengkapnya di halaman Prediction.
Cara Kerja Halaman Prediction dan Model CNN-LSTM
Halaman Prediction adalah fitur inti dari seluruh sistem ini karena di sinilah model Multimodal CNN-LSTM menunjukkan kemampuannya dalam memprediksi kondisi tanaman empat hari ke depan. Ketika pengguna membuka halaman ini dan meminta prediksi, frontend mengirimkan permintaan ke endpoint POST /api/v1/predict/forecast di backend. Backend kemudian melakukan serangkaian proses yang dimulai dengan menyiapkan dua jenis input untuk model, yaitu input berupa data sensor dan input berupa citra tanaman.
Untuk input sensor, backend mengambil data 14 hari terakhir dari database dan melakukan agregasi harian karena dalam satu hari terdapat tiga kali pengukuran. Dari tiga pengukuran tersebut dihitung nilai rata-rata, minimum, dan maksimum untuk kelembaban tanah serta suhu, sehingga setiap hari direpresentasikan oleh sembilan fitur. Data 14 hari ini kemudian disusun menjadi sebuah array berdimensi 14 kali 9 yang akan menjadi input untuk komponen LSTM. Sementara itu, untuk input citra, backend mengambil gambar tanaman terbaru dari folder penyimpanan, mengubah ukurannya menjadi 224 kali 224 piksel agar sesuai dengan kebutuhan model CNN, dan menormalisasi nilai pikselnya ke rentang 0 hingga 1. Citra yang telah diproses ini menjadi input untuk komponen CNN.
Model Multimodal CNN-LSTM sendiri bekerja dengan dua cabang yang berjalan secara paralel sebelum akhirnya digabungkan. Cabang pertama adalah CNN atau Convolutional Neural Network yang bertugas menganalisis citra tanaman. Citra yang sudah diproses masuk ke lapisan Conv2D pertama yang mendeteksi pola-pola dasar seperti tepi dan tekstur pada daun, kemudian masuk ke lapisan MaxPooling yang memperkecil dimensi sambil mempertahankan fitur penting. Proses ini diulang melalui lapisan Conv2D kedua dan ketiga yang semakin dalam sehingga mampu mendeteksi fitur yang lebih kompleks seperti bentuk daun, ukuran, dan warna yang mengindikasikan stage pertumbuhan tertentu. Di akhir cabang CNN, terdapat lapisan GlobalAveragePooling dan Dense yang menghasilkan sebuah vektor fitur visual berjumlah 128 angka yang merepresentasikan karakteristik visual tanaman.
Cabang kedua adalah LSTM atau Long Short-Term Memory yang bertugas menganalisis data sensor time-series. Data sensor 14 hari yang sudah disiapkan sebelumnya masuk ke lapisan LSTM pertama yang memiliki 64 unit dan mengembalikan urutan untuk ditangkap oleh lapisan LSTM kedua dengan 32 unit. LSTM secara khusus dirancang untuk mengingat pola dalam data berurutan, sehingga ia mampu memahami bahwa misalnya kelembaban tanah yang terus menurun selama beberapa hari terakhir mengindikasikan tren kekeringan yang akan berlanjut. Di akhir cabang LSTM, dihasilkan sebuah vektor fitur temporal berjumlah 32 angka yang merepresentasikan pola perubahan kondisi sensor.
Kedua vektor fitur dari CNN dan LSTM kemudian digabungkan menggunakan lapisan Concatenate sehingga menghasilkan sebuah vektor gabungan berjumlah 160 angka. Vektor gabungan ini kemudian diproses melalui lapisan Dense dan Dropout untuk menghasilkan output akhir berupa 12 angka yang merepresentasikan prediksi untuk empat hari ke depan, di mana setiap hari memiliki tiga nilai prediksi yaitu kelembaban tanah, suhu, dan tingkat kematangan. Nilai-nilai prediksi ini kemudian dikembalikan ke skala aslinya melalui proses inverse scaling, dan berdasarkan nilai kematangan yang diprediksi, sistem menentukan stage tanaman menggunakan aturan threshold yang telah ditetapkan, yaitu kematangan di bawah atau sama dengan 32 persen termasuk Initial Stage, 33 hingga 35 persen termasuk Vegetative Stage, 35 hingga 36 persen termasuk Pre-Harvest Stage, dan di atas 36 persen termasuk Harvest Ready. Hasil akhir ini dikirimkan kembali ke frontend dalam format JSON dan ditampilkan sebagai grafik prediksi dengan garis putus-putus untuk empat hari ke depan yang bersambung dengan garis solid untuk 14 hari historis, beserta tabel detail yang menunjukkan angka prediksi untuk setiap hari.
Cara Kerja Halaman History
Halaman History berfungsi sebagai arsip data yang memungkinkan pengguna melihat seluruh catatan pengamatan yang pernah dilakukan terhadap tanaman pakcoy. Ketika pengguna membuka halaman ini, frontend mengirimkan permintaan ke backend dengan parameter halaman dan jumlah data per halaman, misalnya page=1 dan limit=20. Backend kemudian melakukan query ke database dengan pagination sehingga hanya mengembalikan 20 baris data sesuai halaman yang diminta, bukan seluruh 1140 baris sekaligus, demi menjaga performa dan kecepatan loading.
Pengguna juga dapat memfilter data berdasarkan kriteria tertentu seperti rentang hari, stage pertumbuhan, atau kondisi tanah. Ketika filter diterapkan, frontend mengirimkan parameter tambahan ke backend yang kemudian menyesuaikan query database untuk hanya mengembalikan data yang sesuai dengan filter tersebut. Selain melihat data dalam bentuk tabel, pengguna juga dapat mengunduh seluruh data dalam format CSV dengan mengklik tombol Export. Ketika tombol ini diklik, backend akan mengambil seluruh data dari database, mengkonversinya ke format CSV, dan mengirimkannya sebagai file yang dapat diunduh oleh pengguna. Fitur ini sangat berguna bagi peneliti atau mahasiswa yang ingin melakukan analisis lanjutan menggunakan tools lain seperti Excel, Python, atau R.
Cara Kerja Halaman AI Assistant
Halaman AI Assistant menyediakan antarmuka chat yang memungkinkan pengguna bertanya tentang kondisi tanamannya dan mendapatkan jawaban yang kontekstual serta rekomendasi perawatan yang spesifik. Halaman ini bekerja dengan mengintegrasikan Large Language Model melalui API OpenRouter yang menyediakan akses ke model-model gratis seperti Llama 3.1 8B Instruct.
Ketika pengguna mengetik pertanyaan di chat box dan menekan tombol kirim, frontend mengirimkan pesan tersebut ke backend melalui endpoint POST /api/v1/ai/chat. Namun sebelum pesan ini diteruskan ke LLM, backend terlebih dahulu mengumpulkan konteks data terkini yang meliputi kelembaban tanah saat ini, suhu, kondisi tanah, stage pertumbuhan, tingkat kematangan, serta hasil prediksi empat hari ke depan dari model CNN-LSTM. Semua informasi kontekstual ini kemudian digabungkan dengan pertanyaan pengguna ke dalam sebuah prompt yang terstruktur dan dikirimkan ke OpenRouter API.
LLM yang menerima prompt ini kemudian menghasilkan jawaban yang tidak bersifat umum melainkan spesifik terhadap kondisi tanaman pengguna. Sebagai contoh, jika pengguna bertanya apakah perlu menyiram tanaman hari ini dan data menunjukkan kelembaban tanah di angka 50 persen yang masuk kategori Dry, LLM akan menjawab dengan rekomendasi yang memperhitungkan kondisi tersebut beserta prediksi kelembaban empat hari ke depan. Jawaban dari LLM kemudian dikirimkan kembali ke frontend dan ditampilkan dalam gelembung chat yang rapi. Halaman ini juga menyediakan tombol Quick Actions yang berisi prompt-prompt preset seperti Analisis Kondisi, Saran Penyiraman, Prediksi Panen, dan Peringatan Dini, sehingga pengguna yang tidak ingin mengetik pertanyaan secara manual dapat langsung mengklik salah satu tombol tersebut untuk mendapatkan informasi yang relevan.
Cara Kerja Halaman About
Halaman About berisi informasi mengenai sistem secara keseluruhan, mulai dari penjelasan tentang tujuan sistem, metodologi yang digunakan termasuk penjelasan tentang arsitektur Multimodal CNN-LSTM, informasi tentang dataset yang digunakan, hingga kredit dan lisensi project. Halaman ini bersifat statis dan tidak memerlukan panggilan API ke backend karena kontennya sudah tetap. Halaman ini berguna bagi pengguna yang ingin memahami bagaimana sistem bekerja di balik layar, terutama bagi mahasiswa atau peneliti yang tertarik dengan aspek teknis dari model prediksi yang digunakan.
Proses Pelatihan Model
Sebelum website dapat melakukan prediksi, model CNN-LSTM harus dilatih terlebih dahulu menggunakan dataset yang tersedia. Proses pelatihan ini dilakukan secara offline dan hanya perlu dilakukan sekali, atau diulang jika terdapat data baru yang ingin ditambahkan. Proses dimulai dengan memuat file Excel berisi 1140 baris data sensor dan melakukan agregasi harian sehingga didapatkan 380 baris data yang masing-masing mewakili satu hari pengamatan. Setelah itu dilakukan feature engineering dengan menambahkan fitur cyclical encoding untuk hari menggunakan fungsi sinus dan cosinus agar model dapat memahami pola berulang dalam data.
Langkah selanjutnya adalah membuat sliding window dengan ukuran 14 hari untuk input dan 4 hari untuk output. Artinya, untuk setiap sample training, model akan melihat data 14 hari berturut-turut sebagai input dan diminta memprediksi kondisi 4 hari berikutnya. Dari 380 hari data, dihasilkan sekitar 363 sample training. Data ini kemudian dibagi menjadi tiga bagian yaitu training set sebesar 70 persen untuk melatih model, validation set sebesar 15 persen untuk memantau proses training dan mencegah overfitting, dan test set sebesar 15 persen untuk mengevaluasi performa akhir model.
Untuk data citra, seluruh gambar dari folder images dimuat, diubah ukurannya menjadi 224 kali 224 piksel, dan dinormalisasi. Data augmentation juga diterapkan pada gambar training berupa flip horizontal, rotasi kecil, dan perubahan brightness untuk meningkatkan variasi data dan membantu model belajar lebih baik. Setiap gambar kemudian dipetakan ke data sensor berdasarkan hari pengamatan sehingga model dapat menerima kedua input secara bersamaan.
Proses training menggunakan optimizer Adam dengan learning rate 0.001 dan loss function Mean Squared Error. Training berjalan hingga maksimal 100 epoch dengan mekanisme EarlyStopping yang akan menghentikan training secara otomatis jika validation loss tidak membaik selama 10 epoch berturut-turut. Setelah training selesai, model dievaluasi pada test set menggunakan metrik MAE, RMSE, dan R-squared untuk mengukur akurasi prediksi. Model yang telah dilatih kemudian disimpan dalam format .keras beserta scaler yang digunakan untuk preprocessing, sehingga dapat dimuat kembali oleh backend saat website berjalan tanpa perlu melakukan training ulang.
Alur Kerja Deployment
Setelah seluruh fitur selesai dikembangkan dan diuji, sistem di-deploy agar dapat diakses secara publik. Frontend Next.js di-deploy ke Vercel yang secara otomatis melakukan build dan hosting setiap kali ada push ke repository GitHub. Backend FastAPI di-deploy ke Railway atau Render yang menyediakan environment Python untuk menjalankan server. File model CNN-LSTM yang telah dilatih harus disertakan dalam deployment backend agar dapat dimuat saat server dimulai. Database SQLite yang digunakan selama development diganti dengan PostgreSQL dari Neon untuk production agar dapat menangani akses bersamaan. Environment variables seperti API key OpenRouter dan URL database dikonfigurasi di platform deployment masing-masing. Setelah deployment selesai, frontend dan backend terhubung melalui URL API production, dan website dapat diakses oleh siapa saja melalui URL yang diberikan oleh Vercel.
Ringkasan Cara Kerja
Secara ringkas, sistem ini bekerja dengan mengambil data historis sensor dan citra tanaman pakcoy, memprosesnya melalui model Multimodal CNN-LSTM yang mampu memahami baik aspek visual tanaman maupun pola perubahan kondisi lingkungan dari waktu ke waktu, kemudian menghasilkan prediksi kondisi tanaman untuk empat hari ke depan. Hasil prediksi ini disajikan dalam bentuk dashboard interaktif yang mudah dipahami, dilengkapi dengan rekomendasi cerdas dari AI yang membantu pengguna mengambil keputusan perawatan tanaman. Seluruh proses ini berjalan secara otomatis dan real-time setiap kali pengguna mengakses website, tanpa memerlukan intervensi manual yang rumit, sehingga petani atau peneliti dapat memantau dan merencanakan perawatan tanaman pakcoy mereka dengan lebih efektif dan berbasis data.
